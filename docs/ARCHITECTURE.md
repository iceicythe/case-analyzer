# 架构与证据边界

应用由 Python 本地 HTTP 服务和原生 JavaScript 页面组成。没有前端构建步骤，没有数据库服务。输入、结果和队列状态保存为本地文件，默认绑定 127.0.0.1。

## 一条 Case 的数据流

1. **导入**：页面将目录内 CSV 按相对目录分组，忽略标注等非日志文件。通过只读预检逐条检查 CSV、来源和重复编号，再事务提交数据、索引和人工模板。同名 Case 拒绝覆盖，相同输入可跳过。
2. **候选**：车辆车速形成宽松减速候选，严格窗口和合并规则产生数值参考区间。项目事件口径不等于驾驶故障定义。
3. **复核**：有效 AI 配置下，导入成功或服务启动会在后台发现待办并进入持久队列，无需打开页面。校验模型 JSON、证据引用和确认边界；数据缺口、边缘、模型不确定或冲突交给人工。无模型时可以人工确认。
4. **人工关联**：先保存人工区间及整段/来源核查，再将相应事件关联到候选。使用版本指纹防止其他页面的旧内容覆盖已保存结果。
5. **排查**：仅分析已确认区间。读取车辆、目标、规划和控制上下文，按容差匹配采样，分别保留缺失、歧义和有效计数。整理原始行引用、规划原因与目标变化。
6. **建议**：自动队列对确认事件先保存本地报告，再调用 AI 排序；AI 只能返回允许的检查 ID，关键证据缺口必须优先，最多选三项。默认摘要由程序按同一份证据组装，展示首项操作与依据，完整步骤及其他检查可展开。未启用自动模式时可手动生成。
7. **交付**：保存人工检查状态与备注。报告中心导出有效结果及离线 HTML，浏览器草稿不算正式工作记录。

## 模块分工

| 模块 | 职责 |
|---|---|
| `storage.py` | 输入校验、事务导入、来源和哈希 |
| `annotation_protocol.py` / `annotation_assist.py` | 事件窗口、连续性和合并 |
| `candidate_review.py` / `candidate_decision.py` | 候选、模型适配和事件复核约束 |
| `automatic_review.py` | 持久队列、暂停、恢复和显式重试 |
| `human_event_review.py` / `workbench_reviews.py` | 人工关联、有效结果存储和排查衔接 |
| `event_investigation.py` | 多模块取证、匹配、事实、模型输入和报告 |
| `investigation_actions.py` | 原因/目标摘要与具体检查操作 |
| `investigation_summary.py` | 事件简报、优先操作与证据缺口，在线和导出共用 |
| `investigation_tracking.py` | 核查状态、备注、保存冲突 |
| `local_report_tools.py` / `offline_report.py` | 有效报告打包与离线展示 |
| `evaluation.py` | 独立评估空间、匹配与指标计算 |
| `server.py` | 页面和 HTTP API 的装配 |

## AI 接收什么

事件复核和排查是不同步骤。事件复核输入候选相关的车辆片段及对应证据，依照固定规则判断。排查输入已确认区间的事实、质量限制、信号范围、规划原因/目标摘要和允许的检查项。

排查请求不重复发送全部模块原始行和逐点匹配记录；这些留在完整本地证据中。模型据摘要选择排序，不独立重读完整原始日志。该步骤关闭深度思考，事件复核继续使用配置的思考强度。

API Key 仅由服务端从本地配置或环境读取，不写入业务 Prompt，也不从页面接口返回。启用真实模型时，发送的业务内容将离开本机，需使用允许发送的数据。

## 需要保留的区别

- 无匹配记录、匹配歧义、字段为空是不同情况；不能统一解释为没有请求或没有目标。
- 近邻匹配偏差不是时钟校准值，时间共同出现也不证明因果。
- 多目标和 ID 变化需要关联信息，不能拼接为同一条物理轨迹。
- 来源声明与文件完整性可检查；它们不认证采集过程真实性。
- 合法模型输出表示遵守程序约束，不表示排查方向已经由独立专家确认。

## 存储与失败处理

`runtime/` 包含 data、index、annotations、model_reviews、evaluations。数据和配置变化会使旧结果失效，失效报告不能当作当前有效报告导出。普通保存失败和版本冲突保留已有记录。

模型超时、截断或不合规输出保留失败状态；排查仍可使用本地建议。服务中断后无法确认结果的调用不静默重发，需显式重试。单个工作空间通过文件锁限制一个写入服务。

目前未验证断电下的全部多文件恢复、大规模吞吐和长期运行，不应由普通错误回滚测试外推这些能力。
