# 三个可直接导入的演示 Case

样例由本目录 `generate_demo.py` 使用确定公式生成，采用项目 MIT 许可。未使用企业日志、个人驾驶记录或第三方数据集。它们只用于演示功能和构造测试，不能用来声称道路效果或闭环仿真效果。

| 目录 | 设计内容 | 可观察的功能 |
|---|---|---|
| demo_deceleration | 6秒片段，1.5～4.5秒车速按公式下降，四类日志齐全 | 候选筛选、确认、规划/控制证据与排查 |
| demo_multitarget | 同样的车速，每个时刻包含两个目标 | 多目标歧义、规划目标关联待核查 |
| demo_no_event | 车速保持20m/s，仅提供车辆日志 | 无候选的正常处理 |

所有信号都是为说明字段和功能设计的，决策原因不证明场景合理性。样例没有人工真值文件，也没有人为填好的故障根因。`source.json` 仅声明来源，导入时由工具写入工作台的元数据格式。

先按主 README 启动工作台，再在另一个终端运行：

```shell
python scripts/import_demo.py
```

该脚本通过本地 HTTP 接口导入，已有同名 Case 会跳过，导入后不直接确认或生成报告。要体验完全离线的人工流程，启动时使用 `--no-auto-review`。启用自动复核且配置有效 API 时，后续打开 Case 或加入队列可能触发真实调用。

也可在“数据接入”中选择单个目录内的全部 CSV，来源选“合成数据”，填写来源说明和加速度来源；不需要选择 source.json。

重新生成同样的 CSV：

```shell
python examples/generate_demo.py --force
```
